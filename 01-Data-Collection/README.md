# Data Collection

This folder contains notebooks demonstrating different techniques for collecting data used in Machine Learning projects.

## Topics Covered

- Reading and working with JSON data
- Fetching data using APIs
- Web scraping using Python
- Connecting to SQL databases and loading data

## Files

- `jsondata.ipynb` – Working with JSON files
- `trialapi.ipynb` – Fetching data from APIs
- `webscrap.ipynb` – Web scraping basics
- `sqlconn.ipynb` – SQL database connection and data retrieval
