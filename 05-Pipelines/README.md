# Machine Learning Pipelines

This repository contains hands-on implementation of **Machine Learning Pipelines** using Scikit-learn. It demonstrates how to preprocess data, train models, and simplify the complete ML workflow with and without pipelines.

## 📂 Contents

- **titanicNOpipelines.ipynb**
  - Data preprocessing without Pipelines
  - Manual implementation of imputation, encoding, scaling, and feature transformation
  - Preparing data before model training

- **titanicPipelines.ipynb**
  - Building ML Pipelines using Scikit-learn
  - Combining preprocessing and model training
  - Using `Pipeline` and `ColumnTransformer`
  - Cleaner and reusable workflow

## 🎯 Objective

The objective of this repository is to understand how Scikit-learn Pipelines simplify machine learning workflows by combining preprocessing and model training into a single, efficient, and reusable process.
