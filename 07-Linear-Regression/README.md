# Linear Regression

This repository contains my learning and implementation of **Linear Regression**, covering both the theoretical concepts and practical implementations. The notebooks explore how linear regression models are built, trained, evaluated, and optimized using both **scikit-learn** and **from-scratch implementations**.

## Topics Covered

* Simple Linear Regression
* Multiple Linear Regression
* Assumptions of Linear Regression
* Cost Function (Mean Squared Error)
* Gradient Descent
* Batch Gradient Descent
* Model Evaluation
* From-Scratch Implementations using NumPy
* Comparison with scikit-learn

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Purpose

The objective of this repository is to build a strong foundation in Linear Regression by understanding both the underlying mathematics and the implementation details. Along with using machine learning libraries, I have also implemented core algorithms from scratch to gain a deeper understanding of how they work internally.
