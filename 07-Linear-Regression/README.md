# Linear Regression

This repository contains my learning and implementations of **Linear Regression**, covering the mathematical foundations, optimization techniques, regularization methods, and practical implementations using both **scikit-learn** and **from-scratch NumPy implementations**.

The goal is to understand not only how to use regression models, but also how they work internally — including cost functions, gradient descent, regularization, and model evaluation.

## Purpose

The objective of this repository is to build a strong foundation in **Linear Regression and its extensions** by learning the mathematics, implementing algorithms from scratch, and applying them to practical datasets.

Rather than relying only on high-level machine learning libraries, I am implementing important algorithms and optimization techniques from scratch to understand what happens internally.
