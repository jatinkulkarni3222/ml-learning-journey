# Data Preprocessing

This repository contains my hands-on practice notebooks covering essential **Data Preprocessing** techniques used in Machine Learning. These notebooks demonstrate how to prepare raw data before training ML models using **Pandas** and **Scikit-learn**.

## 📂 Contents

- **columnTransform.ipynb**
  - ColumnTransformer
  - Applying different preprocessing steps to different columns
  - Building preprocessing pipelines

- **normalization.ipynb**
  - Min-Max Scaling
  - Max Absolute Scaling
  - Effect of normalization on data

- **onehotencoding.ipynb**
  - One-Hot Encoding
  - Handling Nominal Categorical Features
  - Dummy Variable Trap

- **ordinalencoding.ipynb**
  - Ordinal Encoding
  - Handling Ordered Categorical Features
  - Encoding with predefined category order

- **standardization.ipynb**
  - StandardScaler
  - Feature Scaling
  - Mean = 0 and Standard Deviation = 1
